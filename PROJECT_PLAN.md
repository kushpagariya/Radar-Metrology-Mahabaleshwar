# Demonstration build scope

The user's 10 November 2026 instruction authorizes a frontend-first demonstration, followed by formula-based backend features. Database, authentication and production infrastructure are deferred until the demonstration is accepted. Work stays in the primary Radar-Metrology-Mahabaleshwar folder. The reference portal is read-only reference material.

The revised Beam to Data direction is an expressive light-studio exhibition. The representative radar remains intact while sampled gates open into a spatial data field. Cursor steering, drag rotation, floor wavefronts and a Send a pulse action support exploration. There is no radar-to-PPI card conversion. Two brief supporting sections follow. Mobile and reduced-motion versions use a static poster.

## Current delivery

1. Independent React/TypeScript local app, shared design tokens and accessible navigation.
2. Landing exhibition and research workspace, with labelled deterministic synthetic scans.
3. Direct scan workspace and Data Library, without Overview or a standalone calculator. Functional selection, playback, field/range/display controls, cursor inspection, scan-derived rainfall, schematic map pan/zoom and exports.
4. Local FastAPI service with scientific formulas and temporary NetCDF inspection/selected-sweep processing.
5. Build checks, scientific tests and desktop/mobile visual verification.

## Deferred production phases

1. Obtain original Mahabaleshwar files, verified antenna coordinates, scan specification and station model references.
2. Validate formats and scientific outputs with domain review, Py-ART and a geographic basemap/overlay pipeline.
3. Introduce Supabase Auth, metadata, private storage, ownership and processing workers.
4. Add advanced radar moments, supported RHI, comparisons and research intelligence only as the data supports them.

No gauge upload, gauge validation, gauge-trained correction or operational warning system is included.
